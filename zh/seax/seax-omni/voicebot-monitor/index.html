Dashboard 總覽


本指南旨在協助您快速熟悉「洞察 (Insights)」儀表板的各項功能與數據指標。我們建立此儀表板的目的，是為了讓您所有語音專案（包含來電與外撥）的成效與通話品質達到完全透明化。

請您放心，我們的團隊隨時都在後台為您監控每一通電話的執行狀況。透過這個儀表板，您可以隨時掌握最新進度，而我們也會持續依據這些數據，為您動態優化機器人的溝通邏輯與通話品質。

頂部篩選工具：自訂觀察範圍 #

位於頁面最頂部的控制列，可讓您根據特定時間、特定機器人或通話方向進行精準篩選：


頂部篩選工具


篩選欄位 功能說明 實務應用與建議
工作區 (Workspace) 選擇您要查看的專案群組或工作區。 適用於管理多個不同業務線或專案的客戶。
機器人 (Bot) 點擊下拉選單，可搜尋或指定特定 AI 機器人。 當您同時上線多個測試版本時，可用此欄位進行 A/B 測試的成效對比。
通話方向 (Direction) 篩選「來電 (Inbound)」、「外撥 (Outbound)」或「所有方向 (All directions)」。 您可以根據當下關注的焦點，自由切換查看進線客服狀況或主動外撥成效。
起始/結束日期 (From/To date) 自訂想要檢視的日期區間。 適合用於週報、月報數據拉取。
快速範圍 (Quick range) 提供「過去 7 天」、「過去 30 天」、「過去 3 個月」等快捷鍵。 快速評估近期專案走勢的常用工具。

四大核心指標與分析圖表 #

核心健康指標與四個視覺化分析圖表均展示於儀表板的主體部分。這種整合檢視能讓您瞬間評估專案的即時狀態與變化趨勢。


核心指標與分析圖表


四大核心指標：掌握整體健康度 #

篩選列下方的四個大型卡片，是您每次評估活動成效時最關鍵的「健康指標」：

1. 已分析 (Analyzed) #

  • 定義：系統已成功收集、處理並完成語意分析的總通話通數。
  • 對您的意義：代表此專案累積的數據樣本量。樣本量越大，整體趨勢越具備參考價值。

2. 標記比例 (Flagged rate) #

  • 定義：代表在所有已分析的通話中，「有問題」或「未通過」的電話所佔的百分比。
  • 對您的意義：這是專案優化的關鍵指標。 標記通常代表通話未能順利完成或遇到異常（如：無法理解來電者、AI 代理無回應等）。標記比例若穩定維持在合理低點，代表通話流程運作順暢。

3. 平均信心度 (Avg confidence) #

  • 定義：AI 語音辨識模型對客戶語意理解的平均把握度（百分比）。
  • 對您的意義：這是技術品質的保證。 當平均信心度達到高標準（如 95% ~ 99%）時，代表 AI 能夠精準且無誤地聽懂客戶的回答，請您絕對放心。

4. 平均時長 (Avg duration) #

  • 定義：每通電話從接通到掛斷的平均持續時間（秒）。
  • 對您的意義：協助您評估腳本設計。若時間過短，可能代表客戶較早掛斷；若時間過長，則需檢視流程是否不夠精簡。

視覺化分析圖表：洞察趨勢與異常 #

(註：此圖表之儀表板位置請參考上方章節之整合螢幕截圖)

中段的四個圖表將複雜的數據轉化為直觀的視覺呈現。

💡 強大互動小秘訣：

本儀表板支援動態連動，幫助您輕鬆下鑽分析 (Drill-down)：

  1. 滑鼠懸停看細節：當您將滑鼠游標懸停 (Hover) 在任何圖表的資料柱或折線上時，系統會自動彈出詳細的數據提示框，顯示該節點的精確數值。
  2. 點擊圖表連動清單：當您在圖表中點擊某個具體日期（例如 7/14）的柱狀圖時，頁面最下方的「通話總覽 (Call explorer)」清單將會自動篩選切換，只顯示該日期區間的所有通話紀錄！這讓您在發現異常數據時，能秒速調出當天的電話進行核查。

標記比例趨勢 (Flagged-rate trend) #

  • 圖表類型：長條圖與折線圖結合。
  • 解讀方式：綠色柱狀代表通話總數，藍色折線代表有問題（未通過）電話比例的起伏。若某天折線異常飆高，您可以直接點擊該天的柱狀圖，立刻查看下方的通話總覽。

失敗類別 (Failure categories) #

  • 圖表類型：紅色橫向長條圖。
  • 解讀方式：列出通話未能成功達成目標的主要原因（例如：AI 無法辨識語音信箱、AI 無回應等）。
  • 我們的承諾：這是我們與您攜手優化的核心依據。 我們的團隊會定期分析這些失敗類別，並據此調校機器人的話術、觸發時間或系統設定，幫您將通話品質與轉化率提到最高。

通話量 (Call volume) #

  • 圖表類型：綠色直立長條圖。
  • 解讀方式：展示每日成功執行的通話總數。方便您確認系統整體的處理量與進度。

各機器人標記比例 (Flagged rate by bot) #

  • 圖表類型：機器人對比長條圖。
  • 解讀方式：若您同時啟用多個機器人，此處會對比各個機器人的異常（未通過）比例，幫助您一眼看出哪一個機器人（或哪一個版本）的表現最為穩定。

通話總覽清單：追蹤單筆通話細節 (Call Explorer) #

頁面最下方的「通話總覽」是您的微觀分析工具。當您點擊上方圖表的特定日期，或是想隨機抽查時，可以在此處調閱具體案例。

💡 實用排序技巧：

清單中的各個欄位標題皆支援自訂排序。您可以點擊欄位名稱進行升冪或降冪排列。實務上，我們強烈建議您利用**「開始時間 (Started at)」來檢視最新通話，或者依據「判定結果 (Verdict)」或「信心度 (Confidence)」**來集中排序，快速找出需要優先處理的案例。

清單欄位說明如下：

  1. 開始時間 (Started at)：精確記錄通話建立的時間。

  2. 客戶號碼 (Customer number)：去識別化或完整的客戶聯絡電話。

  3. 判定結果 (Verdict)：

    • pass (通過)：通話順利完成，且符合腳本設定的成功路徑。
    • fail (未通過)：通話中途遇到問題或未能完成設定目標（即上方提到的「被標記 (Flagged)」的電話）。

  4. 已驗證 (Verified Checkbox)：


    已驗證勾選框


    這是團隊協作與管理的強大工具！ 針對「未通過 (fail)」的案例，當您或您的團隊實際聽過錄音、進行人工核實與處理後，可以將此欄位勾選並儲存。透過這個機制，您可以統一集中管理所有需要手動覆核的異常通話，確保每一個有問題的案例都已被妥善追蹤與解決。

  5. 失敗類別 (Failure category)：針對「未通過」的電話，直接標示具體原因（例如：Voicemail misdetected），方便您快速過濾出需要關懷的客戶。

  6. 信心度 (Confidence)：顯示該單筆通話的 AI 語音辨識信心度（%）。

常見問題與支援 #

Q1：如果我看到「未通過」的電話，我該怎麼辦？ #

請不用擔心。「未通過 (fail)」的狀態可能有幾種不同的原因：這可能是通話本身確實遇到了狀況或未達預期目標，但也有可能是系統對「通話成功」的評估判定標準需要針對您的專案進行微調。若您發現未通過的比例偏高，請隨時聯繫我們！我們的團隊會協助您查看具體的通話細節，並幫您調整與優化判定標準，以確保後續數據追蹤的準確性。

Q2：數據是即時更新的嗎？ #

是的，儀表板的數據為接近實時 (Near Real-time) 更新。當一通電話分析完畢後，通常在數分鐘內便會呈現在您的儀表板上。

我們的服務承諾：

這個 Dashboard 不僅是一個數據展示工具，更是我們與您共同守護專案成效的承諾。我們不僅僅是幫您處理電話，更是在幕後透過這些精密指標持續監控、持續學習。

如果您對 Dashboard 的指標有任何疑問，或需要我們協助導出特定數據，請隨時聯繫您的專屬客服窗口！
